# .github — Gobernanza de la organización MinKura

Este repositorio contiene los **archivos de comunidad y gobernanza por defecto** que GitHub aplica a todos los repositorios de la org `minkura` (es público por requisito de GitHub; la excepción está registrada en ADR-0004 del repo [`org`](https://github.com/minkura/org)).

## Contenido

| Ruta | Propósito |
|------|-----------|
| `.github/ISSUE_TEMPLATE/` | Plantillas por defecto de issues (bug, funcionalidad) |
| `.github/pull_request_template.md` | Plantilla por defecto de pull requests |
| `SECURITY.md` | Política de reporte de vulnerabilidades |
| `profile/README.md` | Perfil público de la organización |
| `CODEOWNERS` | Dueños de este repositorio |

Fuente de verdad del proyecto: repo [`minkura/org`](https://github.com/minkura/org).
